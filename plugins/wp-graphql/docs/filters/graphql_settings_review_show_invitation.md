# graphql_settings_review_show_invitation

```php
apply_filters( 'graphql_settings_review_show_invitation', true );
```

Filters whether administrators are invited to the settings review with an admin notice. The notice shows until the settings review is completed or skipped, or until each user dismisses it. Return false to never show it, for example on sites whose settings are managed in code. The Review Settings menu item and the link on the Settings page are not affected. To record the review as done without visiting it, run `wp graphql settings-review skip`.
