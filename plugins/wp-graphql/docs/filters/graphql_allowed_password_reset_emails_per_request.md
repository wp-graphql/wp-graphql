# graphql_allowed_password_reset_emails_per_request

```php
apply_filters( 'graphql_allowed_password_reset_emails_per_request', self::DEFAULT_MAX_EMAILS_PER_REQUEST );
```

Filters how many password reset emails a single GraphQL request may send. A request can ask for many by aliasing the mutation, and the batch limit counts batch entries rather than aliases, so the limit is applied here. Requests past the limit are rejected with an error rather than silently dropped. The error does not depend on whether the account exists.
