# graphql_password_reset_debug_capability

```php
apply_filters( 'graphql_password_reset_debug_capability', 'list_users' );
```

Filters the capability a caller needs to be told why no password reset email was sent. The default is `list_users` because a caller who holds it can already enumerate accounts through WordPress itself, so the reason tells them nothing they could not look up directly. By default only administrators hold it. Lower it to open the debug output up, for example while developing against the anonymous flow.
