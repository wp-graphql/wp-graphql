# register_graphql_settings_review_step

```php
register_graphql_settings_review_step( string $slug, array $config ): void;
```

Registers a step in the WPGraphQL settings review. The settings review walks site administrators through settings and explains the tradeoffs of each. Settings are added to a step with the `settings_review` key of the config passed to register_graphql_settings_field(). A setting whose `settings_review` config doesn't name a registered step is shown in a step for its settings section. Core registers the `access` (order 10), `request-limits` (order 20) and `diagnostics` (order 30) steps.

- **Since:** 2.24.0
- **Source File:** `plugins/wp-graphql/access-functions.php`

## Parameters

- `$slug` (`string`): A unique slug for the step.
- `$config` (`array<string,mixed>`): The step config: `title` (required), `description` and `order` (steps are shown in ascending order, default 100).
