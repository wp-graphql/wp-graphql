WPGraphQL for ACF is a _**FREE**_, open source WordPress plugin that exposes ACF Field Groups and Fields to the WPGraphQL Schema, enabling powerful decoupled solutions with modern frontends.

Below you can find resources to help you get the most out of the plugin.

## Report a Bug

If you think you have found a bug with the WPGraphQL for ACF plugin (and have clear steps to reproduce) please [open an issue on the WPGraphQL for ACF Github Repo](https://github.com/wp-graphql/wp-graphql/issues/new/choose).

Be sure to [search the Issues](https://github.com/wp-graphql/wp-graphql/issues) to see if the bug has already been reported.

The more detail you can provide when reporting a bug, the better we can troubleshoot and come to a solution. The more vague you are in reporting a bug, the less likely we will be able to reproduce and/or find a resolution.

## Feature Requests

If you have an idea for a feature that would make WPGraphQL for ACF better, you can [submit a feature request on Github](https://github.com/wp-graphql/wp-graphql/issues/new/choose).

## Reporting Security Vulnerabilities

If you believe you’ve identified a security vulnerability with the WPGraphQL for ACF plugin, you can [report a vulnerability on GitHub](https://github.com/wp-graphql/wp-graphql/security/advisories/new).
